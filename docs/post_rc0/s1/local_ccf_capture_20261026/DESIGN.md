# Call-scoped same-state observer

The runner creates exactly two coordinate-selected contexts from actual patch extents, and passes a nullable pointer into CPU alignPatch. Each context owns five preallocated frame records. Each OpenMP frame iteration writes only its own record; all allocation and exclusive file writes happen in serial code before or after barriers. No process-global selector, extra alignment iteration, FFT, acceptance or estimator operation is introduced. The raw product is a labeled diagnostic recomputation; native weighted-expression arithmetic is retained verbatim. Truth is external to native execution.

NewFFT's optional float inverse observer brackets the actual fftwf_execute_dft_c2r call. With preserveInput=true, its input is the actual cloned temporary, not the original API argument. Before/after temporary snapshots, API-before/post-DC and API-after snapshots have separate names. The destroyed temporary may contain arbitrary/nonfinite scratch values; its raw bits are retained and its measured Hermitian summary uses null when nonfinite. All scientific input/output arrays and peak/stopping states fail closed on nonfinite values. No Hermitian projection is introduced or assumed. Arrays are lossless host-endian IEEE float32 or float64 with dtype, shape and byte strides, and native layout/normalization metadata.

Absent MC_DIAG_LOCAL_CCF_DIR, runner pointers and FFT observer arguments are null. The original inverse invocation remains in the flag-off branch. A new source build still needs actual identity checks against the retained binary's noisy UP-only output, then capture ON versus that OFF output; source inspection and analytic bit-neutrality cannot substitute for those two producer checks.

Scope is deliberately fixed: CPU DC-hook build; UP-only DCboth+coupledall; group1/bin1, patch3×3, max5/default.5, B150/default CCF downsample, no interpolation/other research flags; j≤2; one128×96×5 movie. GPU and unsupported configurations are rejected before movie access. A nonexisting absolute capture root is exclusively created; all payload files use O_EXCL and a shared64MiB cap. Partial failures remain on disk and prevent normal publication. This is diagnostic-only scope, not reusable production capture policy.

Relevant tests cover actual C2R callback input, preserved API buffer, output bit equality, two-thread disjoint frame records, complete selected-patch coverage, unsupported geometry/root reuse/file overwrite/payload rejection, and rejected coupled offsets remaining null while large separable fallback remains unclipped. Native data and real-product identity remain separately UNRUN until exact source clearance.
