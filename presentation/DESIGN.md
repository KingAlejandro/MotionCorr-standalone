# Motion, corrected

## Style Prompt
A premium, playful science short made for a live hackathon screening. A midnight instrument-panel canvas, huge chalk-white editorial typography, precision-blue motion paths, warm paper annotations, and deliberate Google-colour accents. Microscopy is shown as a labelled synthetic visualisation, never disguised as experimental data. The imagery evolves: wandering frames become an alignment problem, parallel compute lanes become an agent team, and measurements become the punchline. Humour is dry and affectionate. Humans retain the merge button.

## Typography
Inter Display / Inter for display and body, with Arial fallback. Georgia italic for selected comic annotations. DejaVu Sans Mono / monospace for measurements and code. No font binaries are shipped. A source preview uses locally installed fonts.

## Layout
1920x1080. 96px minimum side margins. Primary content stays above y=875. Captions occupy y=918–1020, with a consistent 1560px maximum width and opaque midnight backing. Source/qualification labels stay above captions. No actual application screenshots are implied by the stylised workflow illustrations.

## Motion
30fps, 180 seconds. Deterministic GSAP root timeline. Shared drifting background. Continuous object motion, staggered functional entrances, 0.65s scene dissolves. Large readable holds between meaningful changes. Caption timing authored in seconds. All narrative transitions preserve the departing scene until the incoming scene covers it.
