# Predeclared plan: `--max_io_threads` probe (frozen before any timing)

Authorized as the smallest follow-up to [../baseline-profile-20261026/](../baseline-profile-20261026/README.md). No code, default, or acceptance-packet change; C1 M1 stays held, A13 and K269-CUDA FAIL dispositions unchanged; no qualification rerun.

**Question.** Does the existing `--max_io_threads` flag change the 1313 ms `host read movie` phase and the whole-job wall under a warm cache? The baseline profile measured that phase (55.7% of the movie wall); its cause is unresolved, and this probe tests only whether read concurrency matters, not why.

**Hypothesis H.** Read concurrency materially affects the read phase and the whole job (warm cache). **Refuted** if every timing difference lies within the observed AA noise of this series, or if the phase change fails its repeat direction (rules below). No resolution bound is calibrated from these samples; "observed AA noise" is descriptive.

**Source scope (read-only, e77a51a2).** `--max_io_threads` is parsed at `motioncorr_runner.cpp:142` (positive or -1) and caps `n_io_threads = n_threads` at :2095-2100. `n_io_threads` reaches the host read OpenMP loop (`num_threads(isCompressedMRC ? 1 : n_io_threads)`, :2562), the compressed-MRC reader (:2142) and the session ingest call (:2324). With the pinned `--ingest float` and a plain float MRC only the host read loop is reached; the cap does not touch the session-ingest or compressed paths in this probe. Other formats, routes and worker layouts: UNRUN.

**Reported.** Every wall (and CPU, peak RSS); per variant the pair ratio = mean(its two runs) / mean(the baseline run before and after it); the observed AA numbers: the two baseline AA pairs |B4-B5|, |B8-B9| and each variant's own pair, as percent of their mean; the read-phase and other stage walls from the four profile samples; checks per process: exit code, 14 published files present and equal to the baseline inventory, MRC sum finite and non-constant, ingest witness `movie.mrcs float`, kit identity comparison against timed baseline T01 (differences retained, no tuning, no stop).

**Decision rules fixed now.** H is *supported for a variant* only if (a) both of its runs lie on the same side of both adjacent baseline runs on whole-job wall (repeat direction), and (b) its pair-ratio deviation from 1 exceeds the largest observed AA difference in this series (baseline pairs and variant pairs), and (c) the read-phase wall in the profile samples moves in the same direction. Read-phase monotonicity across caps 1 >= 2 >= 4 >= 6 is reported, not required. H is refuted if no variant meets (a)-(c). Anything else is stated as inconclusive.
