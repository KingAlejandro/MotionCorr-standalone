# Independent scoring contract, fixed before captured optimization

This is a NEW saved-state diagnostic on two already exposed noisy patches, not a native estimator or an accuracy gate. Opus independently reviews objective semantics; Sonnet implements the truth-isolated objective optimizer. No MotionCorr producers, images, SSH, default/gate/ROI changes or new field fitter.

After stage 1 seals all 22 optimizer outcomes and its highest-objective selections (11 fixed starts per patch), the parent independently scores all saved candidates. Truth does not select optimizer starts, settings, iterations, candidate or stopping. The optimizer sees initial captured spectra, weights, native iteration1 and final trajectories only.

Scoring authority: existing noisy_field.npy, SHA256 839c484f08ced435120a3f7c60267b95959bc5c06993f7c3015d61ffa3b95799, from the capture truth-scoring bundle. Original manifest supplies pixel size 0.885 Å/px. At each native center (62,79) and (62,47), desired physical local cumulative trajectory is field[:,cy,62,:] minus the actual captured global-shifts vector; frame 0 is exactly zero. Compare actual cumulative local trajectory s, not the Tr-recentered reported observations. No scalar noise/model floor subtraction or best rigid registration.

Report per frame vectors, unwrapped RMS/p95/max vector errors in px and Å over all five frames including f0. Report optional torus errors separately (42×32 periods), never use wrapped values to upgrade physical errors. These are point-center trajectory measurements and cannot substitute for the fixed-ROI .20/.40/.80 Å scientific contract. No PASS/FAIL scientific classification from these five points.

Compare native final, native iteration1 exit, zero, and the stage-1 selected highest-J outcome, plus all start outcomes descriptively. Truth-point objective value is a scoring-only post hoc evaluation, without truth-seeded optimization. Objective and trajectory comparisons will be interpreted as follows: a higher-J candidate with worse trajectory shows that maximizing this tested diagnostic does not by itself guarantee better recovery; a higher-J candidate with lower error motivates only a future full-trajectory experiment. Neither outcome proves global optimality, generic native equivalence, an upstream noise cause or suitability for adoption. All failures/caps retained. Numeric validation tolerances and optimizer settings stay frozen before captured outcomes.

The raw signed half-plane phase objective and the symmetric-Nyquist trigonometric interpolant of a real map remain separately labeled. Integer-grid and saved-state numerical closure must pass first. Any failed relation changes the scope or stops the diagnostic before optimization, with a versioned amendment; no silent equivalence assertion.
