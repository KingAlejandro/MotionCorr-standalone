# CPU/CUDA difference explanation ledger — 27 October 2026

This is a retrospective analysis of retained evidence, not a GPU run or acceptance decision. Proposed diagnostic: vector RMS of the **difference between applied fields**, per movie/configuration, ≤0.02 Å. Exceeding it requires a named, evidenced explanation. This is not the 0.20 Å truth-accuracy gate, a new release gate, or evidence of scientific equivalence. An accurate field cannot be inferred from backend agreement, and differences between two RMS errors to truth are not the RMS difference between fields.
